One line of weather, at most 140 characters, for a city that does not exist —
written to make a bored commuter smile on the way to work.

## Entry

> Good morning, Nimbopolis: 18° with a light drizzle of confetti. Umbrellas optional, smiles mandatory, and the 8:15 bus is actually on time.

## Run

```sh
python3 main.py
```

The program writes the forecast to `/output/entry.txt` and prints it.
It is deterministic and uses no network.
